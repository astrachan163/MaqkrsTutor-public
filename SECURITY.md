# Security Policy

## Reporting a Vulnerability

Please report security issues privately:

1. Open a [private vulnerability advisory](https://github.com/astrachan163/MaqkrsTutor-public/security/advisories/new) on this repository, or
2. Contact the maintainer via the GitHub profile: https://github.com/astrachan163

Do not open a public issue for vulnerabilities that could expose users or credentials.

## Scope

This repository is a portfolio / foundational demonstration. Treat any credentials, tokens, or service-account material as sensitive even if labeled for testing.
