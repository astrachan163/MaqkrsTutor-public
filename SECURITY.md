# Security Policy

## Reporting a Vulnerability

Please report security issues privately. Open a [private vulnerability advisory](https://github.com/astrachan163/MaqkrsTutor-public/security/advisories/new) on this repository. That is the only security contact.

Do not open a public issue for vulnerabilities that could expose users or credentials.

Questions that are not security reports can go to strachan@uab.edu.

## Scope

This repository is a portfolio / foundational demonstration. Treat any credentials, tokens, or service-account material as sensitive even if labeled for testing.
